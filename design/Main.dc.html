# Markdwn
Éditeur Markdown natif, pensé pour la vitesse.
## Objectifs
- Démarrage sous **150 ms**
- Preview incrémentale, sans clignotement
- Scroll synchronisé bidirectionnel
## Stack
| Couche | Choix |
| ------- | ------------ |
| Shell | Tauri 2 |
| UI | Svelte 5 |
| Éditeur | CodeMirror 6 |
```rust
let html = markdown::render(&source);
```
> Le parsing vit côté Rust : `pulldown-cmark`
> expose les offsets d'octets, ce qui donne
> le scroll sync gratuitement.
