# K2.8 — Panneaux latéraux : dossiers et « Sur cette page »

Cadrage validé le 2026-10-09. Ce document est le point d'entrée de la session
d'implémentation : périmètre complet, décisions prises, points d'ancrage dans
le code. Ne pas re-débattre ce qui est marqué **décidé** ; le reste est à
l'appréciation de l'implémentation.

Principes du projet (rappel, inchangés) : trois modes distincts (Lecture,
Split, Zen) ; tout ce qui touche au disque vit en Rust ; la mise en page reste
dans la webview ; commentaires en français expliquant le *pourquoi*.

## Périmètre (les 8 items, tous retenus)

### 1. Sidebar redimensionnable

- Poignée de drag sur le bord droit de la barre de dossiers.
- Bornes : 180 px min, 480 px max.
- Largeur persistée dans la config (`sidebarWidth`, champ optionnel — pas de
  migration nécessaire, voir § Technique / Persistance).
- La variable `--w-sidebar` est posée en inline sur `.app` (comme
  `--editor-size`) : l'étiquette du mode Zen (`calc(var(--w-sidebar) + 26px)`)
  suit sans travail supplémentaire.

### 2. Refresh de l'arbre

- Bouton « rafraîchir » dans l'en-tête de la sidebar, à côté d'« Ouvrir un
  dossier ».
- Refresh automatique au retour de focus de la fenêtre (événement `focus` /
  visibilité), débouncé.
- **Décidé** : watcher `notify` en Rust sur le dossier ouvert, événements vers
  la webview, refresh débouncé (~300 ms). Le watcher est relancé à chaque
  changement de dossier racine et arrêté quand il n'y a plus de dossier ouvert.
- Le refresh ne doit JAMAIS refermer l'arborescence : dépend de l'item 3.

### 3. Expansion de l'arbre préservée

- Sortir l'état d'expansion et le cache des enfants des `TreeNode` vers le
  store (`state.svelte.ts`), indexé par chemin.
- Conséquence : un refresh (manuel, focus, watcher) remplace les données sans
  détruire l'état d'expansion ; les dossiers disparus du disque sont simplement
  oubliés.

### 4. Synchro avec le document actif

- Au changement de document actif (onglet, ouverture, fichier
  suivant/précédent) : si le document est sous le dossier ouvert, révélation
  automatique (dépliage des ancêtres + scroll + surlignage) — mécanisme
  existant `revealPath` / `revealTick`, à généraliser.
- Réglage on/off dans Paramètres (« suivre le document actif »), activé par
  défaut.
- Hors du dossier ouvert : NE PAS changer de dossier automatiquement (trop
  intrusif) ; le bouton « Révéler dans la barre latérale » reste le geste
  manuel. Exception : l'ouverture depuis l'Explorateur Windows, voir item 5.

### 5. « Ouvrir avec » depuis l'Explorateur Windows

Comportement actuel : le fichier s'ouvre dans un onglet mais la barre de
dossiers continue d'afficher l'ancien dossier, et Alt+↑/↓ navigue dans cet
ancien dossier — arbre et document sont décorrélés.

- **Décidé** : à l'ouverture externe (lancement ET événement `open-file`),
  charger le dossier parent du fichier dans l'arbre et révéler le fichier —
  même comportement que `revealActiveInSidebar`, appliqué systématiquement.
  La barre de dossiers s'affiche si elle était masquée.
- **Décidé** : fix focus dans le callback single-instance — `unminimize()` +
  `set_focus()` sur la fenêtre `main` (limite déjà consignée dans ROADMAP.md ;
  vigilance : Windows bride le vol de focus, à valider en conditions réelles).

### 6. Rail « Sur cette page » (mode Lecture)

- Collapsible : bouton chevron dans l'en-tête du rail ; replié, il laisse une
  fine colonne avec un bouton pour rouvrir (le contenu ne doit pas devenir
  introuvable). État persisté (`tocCollapsed`).
- Redimensionnable en largeur : poignée sur le bord gauche du rail, bornes
  200–420 px, persisté (`tocWidth`).
- Quand le rail est replié, le document reprend la largeur — c'est le bénéfice
  recherché.

### 7. Splitter éditeur / aperçu (mode Split)

- Le `<div class="splitter">` a un curseur `col-resize` mais aucun
  gestionnaire : le rendre réellement draggable.
- Ratio persisté (`splitRatio`, défaut 0.5), bornes raisonnables (20 % / 80 %).
- Si l'implémentation révèle un problème structurel (sync scroll
  proportionnelle), fallback acceptable : retirer le curseur mensonger et
  sortir l'item du périmètre — à signaler dans le compte-rendu.

### 8. Plan en bas de sidebar (Split / Zen)

- Collapsible (en-tête cliquable) et hauteur ajustable par drag sur la
  séparation arbre/plan, bornée (20–70 % de la hauteur de la sidebar).
- États persistés (`outlineCollapsed`, `outlineHeight`).
- L'item 6 de la ROADMAP (plan adaptatif > 25 titres) reste hors périmètre.

## Persistance (technique)

- Nouveaux champs optionnels dans `Config` (`#[serde(default)]`) : pas de bump
  de `SCHEMA_VERSION` — c'est le comportement prévu par `config.rs`.
- Côté front : ajouter les champs à `toConfig()` / `applyConfig()` /
  `resetSettings()` dans `state.svelte.ts`. L'effet d'enregistrement débouncé
  existant couvre les drags (400 ms).
